# Picket Digital brand kit

| File | Use it for |
|---|---|
| `profile-picture-dark.png` (1080×1080) | **Profile picture** on Facebook, Instagram, LinkedIn, X, WhatsApp Business, Google Business Profile. Safe for circle crops. |
| `profile-picture-light.png` (1080×1080) | Alternative profile picture on a cream background. |
| `cover-facebook-1640x624.png` | Facebook page cover photo. |
| `cover-linkedin-1584x396.png` | LinkedIn profile banner. |
| `cover-x-twitter-1500x500.png` | X (Twitter) header. |
| `logo-on-dark-transparent.png` / `.svg` | Full logo for **dark** backgrounds (light text). |
| `logo-on-light-transparent.png` / `.svg` | Full logo for **light/white** backgrounds (dark text). Email signatures, invoices, documents. |
| `mark-on-dark-transparent.png` / `.svg` | Icon only (three pickets) for dark backgrounds. |
| `mark-on-light-transparent.png` / `.svg` | Icon only for light backgrounds. |

Use the `.svg` files for printing or when a designer asks for a "vector" logo.

**Brand colors:** Charcoal `#15171B` · Cedar `#B8642A` · Cedar light `#D9894B` · Golden-hour sun `#F3B547` · Cream `#F6F0E6` · Forest `#1E3A2F`
**Fonts:** Barlow Condensed ExtraBold (headings), Inter (body). Both are free (OFL).
